## Правила

- Нет задачи в TASKS/ — нет кода
- Репозиторий buildable после каждого коммита
- Личные данные пользователя никогда не попадают в публичные seed/source
  файлы: `src/data/seed.js` содержит только пустые массивы для первого
  запуска (TASK_009); авторитетный источник данных пользователя —
  AsyncStorage на устройстве, не репозиторий. Приватный бэкап личных
  данных хранится вне репозитория и не восстанавливается в публичное
  дерево исходников из этого бэкапа.
- Один логический этап — один коммит
- После задачи: обновить docs/STATUS.md
- Deploy и Git Tag — только после успешного прохождения Architecture
  Review Checklist задачи (см. ADR-007, `docs/DECISIONS.md`)

## Проект

**Ministry** — личный журнал теократического служения.
**Владелец:** сопровождающий проекта Ministry.
**Прототип:** `prototype/App.jsx` (React + localStorage) — удалён из
репозитория в TASK_009; см. `docs/ARCHITECTURE.md`.
**Цель:** Expo + React Native на iPhone.
**Данные:** `src/data/seed.js` — пустые массивы для первого запуска
(TASK_009); реальные данные пользователя живут только в AsyncStorage.
