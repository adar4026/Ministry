# TASK_075 — «Ближайшие события»: опустить header на 14 px

**Дата:** 20 сентября 2026
**Статус:** Реализовано, проверено локально в браузере (390 px) — не
закоммичено.
**Скоуп:** только вертикальное положение header-блока экрана
`app/upcoming-events.tsx` (круглая кнопка «назад» + заголовок). Размер
кнопки, размер/стиль заголовка, шрифты, карточки событий, интервалы
внутри карточек, цвета, тени, фон, данные и порядок событий — без
изменений.

---

## 1. Что было

`header` (`app/upcoming-events.tsx`) сидел вплотную к safe-area top:
`SafeAreaView` (`edges: ["top", "left", "right"]`) добавляет только сам
safe-area inset, `header` — `height: 48, justifyContent: "center",
paddingHorizontal: 16`, без какого-либо доп. отступа сверху. На узком
экране (390 px) кнопка «назад» и заголовок оказывались практически под
статус-баром — по кнопке неудобно попадать.

## 2. Что изменено

`header` получил `marginTop: 14` — единственная правка:

```
header: {
  height: 48,
  marginTop: 14,
  justifyContent: "center",
  paddingHorizontal: 16,
},
```

`marginTop` (а не `paddingTop`) сдвигает весь блок как единое целое, не
трогая внутреннее центрирование кнопки и заголовка друг относительно
друга — оба остаются на той же взаимной оси, просто ниже. Значение не
заменяет safe-area расчёт, а добавляется поверх него (`SafeAreaView`
по-прежнему считает реальный inset устройства) — итоговая формула
`safeAreaTop + 14`, а не жёсткая абсолютная позиция. `ScrollView` с
карточками идёт следующим элементом в том же потоке — сдвигается вниз
вместе с header, `content.paddingTop: 4` (отступ первой карточки от
header) не менялся, так что взаимный зазор header → первая карточка
сохранён.

Значение 14 — середина запрошенного диапазона 12–16 px; выбрано и
визуально подтверждено на 390 px (см. §3).

## 3. Проверки (выполнены)

- Dev-сервер (`expo start --web`), браузер, **390 px** (safe-area
  inset = 0 в вебе, поэтому сдвиг виден «в чистом виде»): кнопка «назад»
  и заголовок опустились на 14 px как единый блок, взаимное выравнивание
  не изменилось; замер `getBoundingClientRect()` заголовка — `top: 27.25`
  (было `13.25` при `marginTop: 0`), разница ровно 14 px.
- Первая карточка («Нет предстоящих событий») опустилась вместе с
  header, отступ от заголовка визуально тот же.
- `npx jest app/__tests__/upcomingEventsScreen.test.tsx` — 4/4 зелёные
  (заголовок, back-контрол, пустое состояние, полный список — поведение
  не изменилось, тест не завязан на конкретные px).
- `npx tsc --noEmit` — чисто.
- Консоль браузера — без ошибок.
