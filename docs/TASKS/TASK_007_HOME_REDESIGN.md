# TASK_007 — Home Redesign (экран «Христианская жизнь»)

**Статус:** Утверждён владельцем (макет одобрен в сессии, июль 2026).
**Основание:** ADR-004 (нет TASK — нет кода). Снимает заморозку Главной
(TASK_004) — сознательно, по решению владельца.

---

## 1. Цель

Переоформить Главный экран в стиле, одобренном по макету (эталон — Apple
Health / присланный дизайн «часы за месяц»): крупная карточка-герой с
кольцом прогресса месячной цели, служебный год помесячно, лента последних
событий. Это **визуальный редизайн**: модель данных, агрегация и
`StoreContext` не меняются (ADR-002/003).

Область палитры — **только Главная**. Глобальный `COLORS` не изменяется;
новые цвета живут локально в Home-компонентах. Остальные экраны (Часы,
События, Добавить, Профиль, Таймер) не затрагиваются.

---

## 2. Структура экрана (сверху вниз)

1. **Шапка:** заголовок **«Христианская жизнь»** + строка текущей даты
   («14 июля, понедельник»); справа аватар (→ Профиль). Заменяет прежний
   заголовок «Журнал служения».
2. **Карточка-герой «Часы за месяц»** (`HoursHeroCard`, новый):
   - крупно часы за текущий месяц (`formatHM(hoursDone)`), подпись «за этот месяц»;
   - **кольцо прогресса** `GoalRing` (новый, `react-native-svg`): % от
     `MONTHLY_GOAL`, в центре «N% / из 50 ч»;
   - сегментированный бар «N% до месячной цели»;
   - две плитки: **«До цели осталось»** (`hoursRemaining`) и **«Осталось
     дней»** (`daysLeft`);
   - кнопка **«Начать служение»** → `router.push("/timer")`.
3. **Ближайшие события** — существующий `UpcomingEventsCard`, без изменений.
4. **Текущий служебный год** — существующая сетка месяцев
   (`serviceYearAggregation` → `MonthChip`), все месяцы Сен→Авг. Без
   изменений логики.
5. **Последние события** — **каждое событие отдельной карточкой** (5 шт.),
   **только прошедшие** (`date <= сегодня`); будущие исключены.

---

## 3. Данные (переиспользование, без новой логики)

- `monthProgress(records, now, sessions)` → `hoursDone`, `hoursRemaining`,
  `daysLeft`; `MONTHLY_GOAL = 50`; `formatHM`, `dayWord`.
- `serviceYearAggregation(records, sessions)` — сетка месяцев (как сейчас).
- Последние события: `events.filter(e => e.date <= todayISO)` → sort desc →
  `slice(0, 5)`.
- Кнопка ведёт на существующий маршрут `/timer`.
- **Единый доступ к данным — только через `useStore()`** (ADR-003).

## 4. Явно вне области (v1)

- **«Серия / N дней подряд»** — исключена из v1 (новая логика стриков; при
  необходимости — отдельной задачей). Вторая плитка — «Осталось дней».
- Стих дня — не делаем; шапка статична («Христианская жизнь»).
- Градиенты фона карточки/кнопки — приближены сплошными цветами, без новых
  зависимостей (`expo-linear-gradient` не добавляется). Кольцо — с
  градиентной обводкой на `react-native-svg`. Точные градиенты фона можно
  добавить позже отдельно.
- Перекраска остальных экранов (решение владельца: только Главная).

## 5. Файлы

- Новые: `src/components/GoalRing.tsx`, `src/components/HoursHeroCard.tsx`.
- Правки: `app/(tabs)/index.tsx` (шапка + дата, замена `TodayCard` на
