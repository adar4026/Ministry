## 3. Анализ исходного изображения

- 1254×1254, PNG, 8-bit RGB, без прозрачности.
- Артворк (скруглённый квадрат с градиентом + белая «M»-монограмма в
  виде раскрытой книги + золотые часы) практически доходит до краёв
  холста; за пределами скруглённых углов — почти белый фон (typical
  "app icon mockup" рендер), не часть бренд-идентики.
- Скругление углов запечено в пиксели — требовало устранения, чтобы не
  конфликтовать с платформенным маскированием (iOS/Android сами
  скругляют/маскируют квадратный источник).

## 4. Выполненные преобразования (механические, без редизайна)

1. **Устранение запечённого скругления углов:** для каждого из 4 углов
   вписанный локальный линейный фит цвета (per-channel, по координатам
   строка/столбец) по чистым фоновым пикселям в увеличенном контекстном
   окне применён для заполнения только зоны скругления (near-white,
   ограничено окном угла) — гладкое продолжение существующего
   градиента/бликового канта, не выдумывание новых элементов. Итоговый
   квадрат — edge-to-edge, без скруглений, без белой рамки.
   - Первая попытка (глобальный nearest-neighbor fill) дала артефакт
     "звёздного" ореола в двух углах из-за секторной природы
     nearest-neighbor на изогнутой границе — отклонена, заменена на
     локальный линейный фит (см. выше), артефакт устранён (проверено
     визуально).
2. **Попытка автоматического cutout марки (M + часы) с прозрачностью:**
   протестирована (цветовые пороги + отклонение от фитированного
   градиентного поля + морфологическая очистка) — результат оказался с
   дефектами (разорванная дуга кольца часов, "блинистая" форма стрелок,
   отдельные шумовые пятна) из-за глянцевого 3D-рендера с собственным
   освещением/тенями на самой марке. Ручная дорисовка была бы
   редизайном — запрещена явно. **Решение (согласовано с владельцем,
   вопрос через AskUserQuestion):** foreground = весь плоский артворк
   (градиент + марка, углы без скругления) целиком, вписанный в
   Android safe zone на прозрачном холсте; background = сильно
   размытая версия того же артворка (тот же градиент/направление
   цвета, без геометрии марки, cutout не требуется).
