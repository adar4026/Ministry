# TASK_051 — Порядок метаинформации в «Ближайших событиях»

**Статус:** завершено, задеплоено (один коммит вместе с TASK_050 —
`fix(events): refine upcoming metadata`, по решению владельца; продолжает
TASK_050)
**Область:** только порядок двух элементов статус-строки в
`UpcomingEventRow.tsx`.
**Не входит:** расчёт дат, границы срочности, цвета (TASK_049/TASK_050 —
без изменений), структура карточек, содержимое `Сегодня`/`Просрочено`/
`Завтра`.

---

## 1. Цель

Абсолютная дата — первой, затем `·`, затем относительный срок:
`4 сентября · Через 15 дней` вместо прежнего `Через 15 дней · 4 сентября`.
Касается только строк, где `label.secondary` не `null` (`overdue` / `soon`
/ `upcoming`) — для `Сегодня`/`Завтра`/`Просрочено`/`later` secondary уже
был `null`, порядок менять нечего.

---

## 2. `UpcomingEventRow.tsx`

`statusRow` теперь рендерит `label.secondary` (+ `·`) первым блоком, затем
блок относительного срока (двухцветный `Через N дней` из TASK_050, либо
единый `Text` с `URGENCY_COLOR[label.urgency]` для `overdue`). Только
порядок двух уже существующих блоков поменян местами — ни один из них не
изменён по содержимому/цвету/структуре. Комментарий в `styles.statusRow`
(пример строки для `flexWrap`) обновлён на новый порядок.

`upcomingDateLabel()` (`src/data/dateFormat.ts`) не менялась — `primary`/
`secondary`/`days`/`urgency` возвращаются в прежнем составе и смысле;
порядок — целиком забота рендера.

---

## 3. Тесты

Изначально ни один существующий тест не проверял порядок `primary`/
`secondary` в разметке (только их наличие через `toContain`) — исходный
прогон `npx jest` после реализации подтвердил отсутствие регрессий без
изменений в тестах.

По отдельному запросу владельца добавлен прямой regression-тест порядка
в `src/components/dashboard/__tests__/UpcomingEventRow.test.tsx` (блок
«TASK_051 metadata order»), привязанный к фиксированному системному
времени (`2026-08-20`), чтобы использовать буквальные строки из ТЗ:

- три ребёнка `statusRow` читаются напрямую по позиции
  (`relative.parent.children`) — дата → `·` → относительная фраза с
  полным `accessibilityLabel="Через 15 дней"` — без сравнения всего
  дерева/снапшота;
- повторно проверены цвета уже в новом порядке: `DS.navy` на словах,
  `DS.todayInk` на числе (`"15"`), `DS.subInk` на дате.

Итого добавлено 3 теста (было 5 в файле после TASK_050 → стало 8).
