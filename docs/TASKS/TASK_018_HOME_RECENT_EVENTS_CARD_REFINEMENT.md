# TASK_018 — Home: карточка «Последние события» — бейдж, формат даты, точный срок

**Статус:** В РАБОТЕ.
**Основание:** ADR-004 (нет TASK — нет кода). Запрошено владельцем напрямую.

---

## 1. Цель

Уточнить карточку события в секции «Последние события» (`EventCard`,
`app/(tabs)/index.tsx`), не переделывая секцию целиком:

1. Бейдж категории переносится в правый нижний угол карточки — не занимает
   горизонталь заголовка.
2. Заголовок события получает максимум доступной ширины, аккуратно
   обрезается многоточием.
3. Дата отображается в формате `DD-MM-YYYY` вместо `YYYY-MM-DD`
   (только на уровне рендера — хранение и модель данных не меняются).
4. Рядом с датой добавляется точный календарный срок с момента события
   (годы/месяцы/дни, корректная русская плюрализация, без нулевых единиц,
   `"Сегодня"` для сегодняшней даты).

## 2. Область изменений

- `src/data/dateFormat.ts` (новый) — чистые функции: `formatDateDMY`,
  `calendarElapsed`, `formatElapsedRu`. Без зависимостей от `Date`
  часового пояса устройства сверх обычного `new Date()`.
- `src/components/dashboard/EventCard.tsx` — layout: строка метаданных
  (дата + срок) отдельно от строки заголовка; бейдж абсолютно/flex-позиционирован
  в правый нижний угол.
- Тесты: `src/data/__tests__/dateFormat.test.ts` (новый),
  `src/components/dashboard/__tests__/EventCard.test.tsx` (новый или
  дополненный).

## 3. Вне области (не трогаем)

- Модель данных `MinistryEvent`, `StoreContext`, формат хранения даты
  (`YYYY-MM-DD` в данных не меняется).
- Другие карточки Главной, другие экраны, навигация.
- Цвета категорий (`CAT` в `src/data/constants.ts`) — переиспользуются как
  есть.

## 4. Поведение для граничных случаев

- Событие сегодня → `"Сегодня"`.
- Будущая дата (данные некорректны/из бэкапа) → безопасный фолбэк без
  краша; секция «Последние события» и так предназначена для прошлых
  событий, редизайн под будущие даты не делается.

## 5. Проверки

- `npx tsc --noEmit`, `npx jest`, `npx expo export --platform web`.
- Визуальная проверка карточки с длинным заголовком и длинной категорией
  на узком экране (375×812).
