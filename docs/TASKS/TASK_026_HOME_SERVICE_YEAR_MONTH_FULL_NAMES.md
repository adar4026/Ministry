# TASK_026 — «Текущий служебный год»: полные названия месяцев без года, синий акцент

**Статус:** ПРИНЯТА владельцем, зафиксирована.
**Основание:** ADR-004 (нет TASK — нет кода). Запрошено владельцем напрямую.

---

## 1. Цель

В сетке месяцев карточки «Текущий служебный год» (компонент `MonthChip`):

1. Убрать год из подписи месяца (`Сен 2025` → `Сентябрь`).
2. Показывать полное название месяца без сокращений (используя уже
   существующий массив `MF` в `src/data/constants.ts` — сокращённый `MN`
   там же не трогается, используется в других местах, например
   `app/(tabs)/hours/history.tsx`).
3. Название месяца — выразительным синим цветом, гармонирующим с текущей
   палитрой (кандидат: `COLORS.accent` = `#3b82f6`, уже используется в
   проекте — точка пионера в `CAT.pioneer.dot`, всё ещё отличается от
   `COLORS.blue` = `#1e3a5f`, которым уже окрашено значение часов ниже, —
   визуальная иерархия «ярче сверху / темнее и крупнее снизу»).
4. Расположение названия над значением часов — без изменений.
5. Не менять: крупную надпись периода (`2025–2026`), сумму часов справа
   (`SummaryCard.meta`), значения часов по месяцам, порядок месяцев, сетку,
   размеры карточек, шрифт интерфейса (без засечек — не меняется, задача
   не трогает `fontFamily`).

## 2. Область изменений

- `src/components/MonthChip.tsx` — единственный производственный файл:
  импорт `MF` вместо `MN`, `{MF[record.month - 1]}` вместо
  `{MN[record.month - 1]} {record.year}`, цвет `styles.month`.
- `src/components/__tests__/MonthChip.test.tsx` — тест «renders the
  month/year label alongside the rounded hours» ожидал `"Июл"` и `"2026"`;
  обновляется на `"Июль"` без утверждения про год (год больше не
  рендерится этим компонентом).

## 3. Важное архитектурное уточнение (решение владельца)

`MonthChip` — общий компонент: используется не только на Главной
(`app/(tabs)/index.tsx`), но и на экране `/hours`
(`app/(tabs)/hours/index.tsx`) для идентичной сетки месяцев служебного
года. Изначальная формулировка задачи ограничивала область только
карточкой на Главной; при реализации обнаружено, что это физически один
и тот же компонент на обоих экранах (см. `docs/STATUS.md`, TASK_017:
«вложенный тайл, не карточка верхнего уровня»). **Владелец подтвердил:**
менять `MonthChip` напрямую — эффект на `/hours` ожидаем и приемлем
(единообразный вид на обоих экранах). `/timeline` этот компонент не
использует вообще и не затрагивается.

## 4. Вне области (не трогаем)

- `SummaryCard` (контейнер карточки), `serviceYearAggregation`,
  `svcYear`, `formatHM` — логика и форматирование периода/суммы часов.
- `MN` (сокращённые названия) — остаётся для `hours/history.tsx`.
- `/timeline`, `/hours/stats` (использует независимый
  `ServiceYearStatsCard`, без `MonthChip`).
- `AGENTS.md` — не открывается, не изменяется.

  статических маршрутов.

  Главная и `/hours`: `Сентябрь` и `Февраль` (самые длинные полные
  названия) — без обрезания, `ellipsis` или нежелательного переноса;
  `document.documentElement.scrollWidth === window.innerWidth` на всех
  трёх ширинах; период `2025–2026` и сумма часов (`510 ч`) не изменились;
  `/hours` (общий компонент `MonthChip`) отображает то же самое
  единообразно; консольных ошибок нет (только предсуществующее SVG-
  предупреждение `transform-origin`, не связанное с этой задачей —
  см. TASK_017).
