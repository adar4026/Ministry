# TASK_032 — Редизайн страницы «История»

**Дата:** Июль 2026
**Статус:** В работе

## 1. Запрос владельца

Полная переработка страницы «История» (`app/(tabs)/hours/history.tsx`)
по двум референсным iOS-скриншотам (приложены владельцем в сессии).
Первый этап — структура второго референса: шапка → календарная сетка
текущего календарного месяца → заголовок месяца/года → плоский список
исходных записей месяца. Без переключателей периода, блока «Всего»,
экспорта, перехода между месяцами — это отдельные будущие задачи.

## 3. Изученная архитектура

- `app/(tabs)/hours/history.tsx` — единственный экран-цель. Текущая
  версия показывает **всю** историю (все служебные годы → месяцы →
  строки, включая legacy-строки для месяцев без Session) через
  локальный `buildHistory()`. Эта модель полностью заменяется —
  `buildHistory()`, `HistoryRow`, `MonthGroup`, `YearGroup` удаляются
  из экрана как неиспользуемые после переписывания.
- `legacyEntryBlockReason()` (`src/data/constants.ts`) блокирует
  создание legacy `HourRecord` для **текущего** календарного месяца
  безусловно (`reason: "current"`) — значит текущий месяц никогда не
  имеет legacy-записи, и новый экран может опираться исключительно на
  `Session[]`, без ветки legacy.
- `buildMonthGrid()` + `WEEKDAYS_SHORT` (`src/data/calendarGrid.ts`) —
  уже реализуют геометрию сетки месяца с понедельником первым днём
  недели (owner requirement из TASK_030, `MonthCalendarModal.tsx`);
  переиспользуются как есть, без изменения порядка недели.
- `sessionsForMonth()` (`src/data/stats.ts`) — единственный источник
  записей месяца; переиспользуется, не дублируется.
- `ClockIcon` (`src/components/icons.tsx`) — переиспользуется для
  строки списка. Круглая кнопка «Назад» референса не имеет готового
  компонента в проекте (все существующие «Назад» — текстовые:
  `timer.tsx`, `entry.tsx`, `upcoming-events.tsx`) — не вводится новая
  SVG-иконка, вместо этого существующий `ChevronRightIcon` разворачивается
  на 180° внутри круглого `Pressable` (тот же набор иконок, не второй
  несовместимый паттерн).
- `HOURS_COLORS` (`src/components/hours/hoursTokens.ts`, TASK_031) —
  базовая цветовая система модуля «Часы»; расширяется точечными
  значениями под референс (светло-фиолетовый фон дня с записями,
  тёмно-фиолетовый акцент текущего дня), не переопределяется.
- Нижний таб-бар — `paddingBottom: 90` уже задан на уровне
  `Tabs.sceneStyle` (`app/(tabs)/_layout.tsx`), применяется ко всем
  экранам вложенного Stack `hours/_layout.tsx`, включая `history` —
  подтверждено тем же выводом TASK_031 для `hours/index.tsx`, отдельного
  изменения не требуется.
- `formatHM()` (`"3 ч 30 м"`) — не подходит под требуемый формат
  `H:MM`; не изменяется (используется в других местах), рядом
  добавляется независимый `formatClockDuration()`.
- `MN`/`MF` (именительный падеж без точки: `"Июл"`/`"Июль"`) — не
  подходят под сокращённую родительную форму с точкой (`"июл."`) для
  строки списка; не изменяются, рядом добавляется независимая таблица
  в `dateFormat.ts`.

## 4. Подтверждённые решения (владелец)

1. **Порядок недели** — понедельник первый (`ПН ВТ СР ЧТ ПТ СБ ВС`),
   вопреки воскресенью-первым на референсе — сохраняется существующий
   порядок проекта (`WEEKDAYS_SHORT`), `MonthCalendarModal` не меняется.
2. **Время в списке записей** — `startTime` показывается только для
   `source: "timer"`; для `source: "manual"` — только дата, без
   времени. `createdAt` никогда не показывается пользователю как время
   служения — используется исключительно как технический критерий
   сортировки.
3. **Сортировка списка** — по `date` убыв.; при совпадении дня — по
   `startTime`, если оно есть, иначе по `createdAt`.
4. **Источник данных** — только `useStore().sessions` за текущий
   календарный месяц; legacy `HourRecord` не учитывается (обоснование —
   п.3 выше).
5. **Шрифт** — системный (iOS: San Francisco без явного `fontFamily`,
   уже так по умолчанию у RN; web: `-apple-system, BlinkMacSystemFont,
   "SF Pro Display", "SF Pro Text", sans-serif` через
   `Platform.OS === "web"`-guard). Никаких файлов шрифтов не
   добавляется.
6. **Референсные размеры** — воспроизводятся близко к скриншотам на
   эталонной ширине 390px; на 320px адаптация только через отступы/gap/
   ширину ячеек, в последнюю очередь — через уменьшение шрифта под
   отдельным правилом для узкого экрана.
7. **Компоненты** — `src/components/hours/HistoryCalendar.tsx`
   (props-only: `year`, `month`, `dailyMinutes`, `today`; без доступа к
   стору, без агрегации внутри) и, при необходимости для читаемости
   теста, `HistorySessionRow.tsx`.

## 5. Новые чистые функции

- `dailyMinutesForMonth(sessions, year, month): Map<number, number>` —
  `src/data/stats.ts`, рядом с `sessionsForMonth`/`monthTotal`.

  двузначные.
