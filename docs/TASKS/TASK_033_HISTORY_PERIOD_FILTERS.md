## 4. Решения

1. **Календарь и список ниже переключателя** остаются завязаны на
   выбранный в UI месяц (`viewYear`/`viewMonthIndex0`), а не жёстко на
   текущий месяц — это и есть требование «Календарь должен отображать
   именно выбранный месяц» для режима «Месяц». В режиме «Год»/«Всё
   время» эти же `viewYear`/`viewMonthIndex0` не сбрасываются — стрелки в
   режиме «Год» двигают только год, `viewMonthIndex0` не трогается
   (требование §3/§4 задания), в режиме «Всё время» стрелки disabled и
   ничего не двигают.
2. **Карточка «Итого»** считается отдельной чистой функцией
   `totalMinutesForPeriod(sessions, period, year, month)` — не завязана
   на `dailyMinutes`/`monthSessions`, которые остаются нужны только
   календарю и списку.
3. **Многодневные/многозаписные дни** — при клике на день с 1 записью
   сразу переход на `/entry?id=...`; при 2+ записях — модал-список
   (переиспользует `Modal.tsx`) с выбором конкретной записи; день без
   записей не кликабелен (ячейка остаётся `View`, не `Pressable`).
4. **Формат «Итого»** — новая `formatDurationRu(totalMinutes)`
   (`src/data/constants.ts`), всегда обе части («0 часов 0 минут»,
   «46 часов 0 минут»), переиспользует уже существующие
   `formatHoursWord`/`formatMinutesWord` (не дублирует склонение).
   Независима от `formatHM()`/`formatClockDuration()`, которые другие
   экраны/этот же экран продолжают использовать без изменений.
5. **Переключатель периода и навигация** — новые локальные компоненты
   `src/components/hours/PeriodSwitcher.tsx` и `PeriodNav.tsx`, тем же
   паттерном, что `HistoryCalendar.tsx`/`HistorySessionRow.tsx` —
   props-only, стили через `historyTokens.ts` (точечно расширяется, не
   переопределяется).
