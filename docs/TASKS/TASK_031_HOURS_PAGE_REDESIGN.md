# TASK_031 — Редизайн страницы «Часы»

**Дата:** Июль 2026
**Статус:** В работе

## 1. Запрос владельца

Полная переработка страницы «Часы» (`app/(tabs)/hours/index.tsx`) из
перегруженного дашборда в минималистичный центр управления учётом
времени, в стиле Apple/iOS, согласованный визуально с уже
редизайненным экраном «Добавить время» (TASK_030). Полный текст
запроса (на русском) сохранён в истории сессии.

Убрать: блок «Текущий служебный год» (сетка `MonthChip`), кольцо
месячного прогресса, чипы «До цели осталось»/«Осталось дней», статус
темпа, тепловую карту, текущий ряд из четырёх узких карточек
(`QuickActionsRow`). Оставить: таймер (как главный визуальный элемент,
в крупной карточке сверху), и компактный сгруппированный список из
трёх пунктов — «Добавить время», «История», «Статистика».

## 4. Технические решения

1. **Таймер встраивается напрямую**, без навигации на отдельный экран
   для стандартных состояний (idle/running/paused) — новый компонент
   `src/components/hours/TimerHeroCard.tsx` использует тот же
   `useTimer()` хук (ровно те же вызовы `start/pause/resume/stop/save`,
   что и `timer.tsx` — бизнес-логика не меняется, `useTimer.ts` и
   `src/data/timer.ts` не трогаются). Редкие состояния
   `recovery-screen`/`clock-rollback` не дублируются в карточке —
   показывается компактный баннер со ссылкой на существующий полный
   экран `/hours/timer`, где эта логика уже реализована и проверена на
   физическом устройстве (TASK_030 follow-up).
2. **`timer.tsx` не изменяется вовсе** — риск регрессии в недавно
   верифицированном на iPhone экране (haptics, recovery, calendar)
   выше пользы от переиспользования JSX; вместо этого сохранение через
   Save-форму реализовано заново в `TimerHeroCard` теми же вызовами
   `useTimer().save()`/`prefillMin` — это не бизнес-логика, а
   независимое представление.
3. **Design tokens** — новый локальный файл
   `src/components/hours/hoursTokens.ts`, значения идентичны
   `ADD_TIME_COLORS` (та же страница-референс по ТЗ владельца), но
   отдельный файл — тот же паттерн, что `entryTokens.ts` не
   переиспользуется другими экранами напрямую.
4. **Иконки для строк списка** — новые `PencilIcon`/`ListIcon`/
   `ChevronRightIcon` добавлены в существующий `src/components/
   icons.tsx` (тот же минимальный `react-native-svg` line-стиль, не
   emoji, без новых зависимостей).
5. **Статус таймера не кодируется только цветом** — везде текстовая
   подпись состояния («Не запущен» / «Идёт» / «Пауза»), цвет — только
   дополнительный акцент.
6. **`MonthSummaryCard.tsx`/`QuickActionsRow.tsx` удаляются** (не
   оставляются как мёртвый код) — единственные потребители убраны этой
   задачей, тестовых файлов не было.
7. **Тепловая карта** — не переносится и не удаляется, остаётся
   нетронутой на `/hours/stats` (уже используется там, п.5 ТЗ).
