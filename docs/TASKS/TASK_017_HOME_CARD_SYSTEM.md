# TASK_017 — Home: единая система карточек (высокий контраст)

**Статус:** В РАБОТЕ.
**Основание:** ADR-004 (нет TASK — нет кода). Запрошено владельцем напрямую
(скриншот стороннего приложения как референс): карточки должны читаться как
ярко-белые поверхности на заметно более тёмном фоне, единообразно по
скруглению/тени/фону. Начинаем с Главной — остальные экраны (общий `Card` в
`src/components/ui.tsx`, используемый вне Home) сознательно вне области этой
задачи.

---

## 1. Цель

Унифицировать визуальный «язык карточек» на Главной (`app/(tabs)/index.tsx`)
и увеличить контраст между фоном экрана и белыми карточками, не меняя оттенок
(hue) фона — только его светлоту, и не меняя ни одну модель данных/логику.

## 2. Область изменений

- `src/components/dashboard/tokens.ts` — `DS.homeBase` и `HOME_GRADIENT`
  затемнены (та же sage/mint-серая гамма, ниже светлота) для более заметного
  контраста с `DS.cardBg` (`#ffffff`, не меняется). Инвариант «`homeBase`
  равен последней точке `HOME_GRADIENT`» сохранён.
- `src/components/dashboard/EventCard.tsx` — скругление карточки события
  выровнено с остальными карточками Главной (было `18`, единая система —
  как у `SummaryCard`/`HoursHeroCard`).
- `src/components/UpcomingEventsCard.tsx` — переведена с общего `Card`
  (`src/components/ui.tsx`, используется вне Home: формы, `/add`,
  `/timeline`, `/hours/history` — не трогаем) на `SummaryCard` из
  `src/components/dashboard` — тот же примитив, что и у остальных карточек
  Главной, вместо параллельной, чуть отличающейся реализации.
- Все карточки Главной остаются на `DS.cardBg` (`#ffffff`), без границ —
  выделение только через фон + тень, как на референсе.

## 3. Вне области (не трогаем)

- Общий `Card` в `src/components/ui.tsx` и все экраны/формы, которые его
  используют (`/add`, `/timeline`, `/hours/history`, формы Event/Talk/
  Session, `BackupSection` на Профиле) — унификация этих экранов, если будет
  одобрена, отдельная будущая задача.
- `MonthChip` (вложенный тайл внутри карточки служебного года) — не
  самостоятельная карточка верхнего уровня, вне области.
- Модель данных, `StoreContext`, навигация, любая бизнес-логика — без
  изменений.

## 4. Проверки

- `npx tsc --noEmit`, `npx jest` (полный набор), `npx expo export --platform
  web` — без регрессий.
- Визуальная проверка на 375×812 и 414×896: карточки Главной визуально
  выделяются на затемнённом фоне; фон вне карточек сохраняет прежний
  зеленовато-серый оттенок, просто темнее; нижние секции (после исчезновения
  градиента) получают тот же более тёмный плоский фон.
