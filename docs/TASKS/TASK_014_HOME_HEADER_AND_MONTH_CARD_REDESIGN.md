# TASK_014 — Home: шапка + карточка текущего месяца ("Ministry Calm")

**Статус:** В РЕАЛИЗАЦИИ.
**Основание:** ADR-004 (нет TASK — нет кода). Владелец утвердил объём и
визуальное направление в отдельном сообщении ("Ministry Calm": спокойный,
premium, mobile-native, в духе Apple Health/Linear). Продолжает TASK_007/
TASK_010 (Home Redesign) — не отменяет их, сужает и переоформляет только
шапку и карточку месячного прогресса.

---

## 1. Цель

Только визуальный редизайн верхней части Главной (шапка + карточка текущего
месяца) — плюс минимальные локальные расчёты/форматирование, напрямую
нужные этим двум зонам. Модель данных, агрегация, `StoreContext`,
персистентность и маршруты не меняются (ADR-002/003).

## 2. Область изменений (разрешено трогать только это)

- `app/(tabs)/index.tsx` — только шапка: формат даты
  ("Пятница, 17 июля" — день недели с заглавной буквы первым), размер
  аватара (40 → 35, т.е. в пределах 10–15% меньше), локальные отступы шапки.
- `src/components/dashboard/HoursHeroCard.tsx` — карточка месяца:
  убрана надпись «Этот месяц», добавлен динамический «ИЮЛЬ 2026» (месяц +
  год, из реальной даты); главная метрика — накопленные часы, округлённые
  до 5 минут только для отображения; подпись «из цели N часов»; меньшее и
  визуально второстепенное кольцо прогресса; новый тонкий линейный
  прогресс-бар (тот же процент, что и кольцо); нижняя строка из трёх
  метрик (Осталось / N дней / В среднем) с иконками; футер — «Детали»
  (существующий маршрут деталей месяца) и пилюля «+ Добавить»
  (существующий маршрут ручного ввода часов).
- `src/data/constants.ts` — один новый форматтер `formatHMRounded()`,
  переиспользующий существующий `roundDurationToNearestFive()` (TASK_011) —
  единое правило округления для всех длительностей этой карточки.
- `src/components/icons.tsx` — добавлена `ClockIcon` (тот же минимальный
  SVG-стиль, что и у существующих иконок; часового значка ранее не было).
- Тесты: `src/components/dashboard/__tests__/HoursHeroCard.test.tsx`
  (обновлён под новый вид), `src/data/__tests__/constants.test.ts`
  (добавлены кейсы для `formatHMRounded`), новый
  `app/__tests__/homeHeaderDate.test.ts` (чистая функция форматирования
  даты шапки).

## 4. Данные и расчёты (переиспользование, без новой агрегации)

- `monthProgress(records, now, sessions)`, `MONTHLY_GOAL`, `dayWord`,
  `formatHoursWord` — без изменений.
- **Округление только для отображения (TASK_014):** `formatHMRounded()`
  строит округлённую до 5 минут строку "X ч Y м" из точного значения в
  часах, не изменяя и не перезаписывая исходные `hoursDone` /
  `hoursRemaining` / `requiredPerDay` — они по-прежнему точные значения
  из `monthProgress()`. Округляется только то, что попадает в `<Text>`.
  Основа — существующий `roundDurationToNearestFive(totalMinutes)`
  (round-half-up, корректный перенос через час), а не новая ad hoc
  реализация.
- Процент цели: как и раньше (`GoalRing`), текст показывает истинный
  (не клампированный) процент, кольцо и линейный бар клампируются к
  0–100% визуально — поведение, уже существовавшее в `GoalRing` до этой
  задачи, не переизобретается.
- «Цель не задана»: `MONTHLY_GOAL <= 0` — существующая защитная ветка,
  без UI редактирования цели (тот же прецедент TASK_010).
- «Детали» переиспользует существующий маршрут `/hours/month/[key]`
  (ключ `YYYY-MM` — тот же формат, что уже строит экран «Часы»), «+
  Добавить» переиспользует существующий `/hours/entry` — без новых
  маршрутов и без дублирования форм/логики сохранения.
