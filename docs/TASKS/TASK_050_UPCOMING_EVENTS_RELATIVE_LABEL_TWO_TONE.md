# TASK_050 — Двухцветная разметка «Через N дней» в «Ближайших событиях»

**Статус:** завершено, задеплоено (один коммит вместе с TASK_051 —
`fix(events): refine upcoming metadata`, по решению владельца)
**Область:** только визуальное разбиение строки `Через N дней` на слова и
число (`UpcomingEventRow.tsx`, `src/data/dateFormat.ts`).
**Не входит:** расчёт дат, границы срочности (7/30 дней), структура
карточек, `Сегодня`/`Просрочено`/`Завтра`, абсолютная дата после `·`.

---

## 1. Цель

Для строк вида `Через 15 дней` (диапазоны `soon` 2–7 дн. и `upcoming` 8–30
дн., TASK_049):

- `Через` и `дней`/`дня`/`день` — основной тёмно-синий цвет интерфейса
  (`DS.navy`), не цвет уровня срочности;
- само число (`15`, `22`…) — оранжевое (`DS.todayInk`, введён в TASK_049
  для `Сегодня`);
- дата после `·` — без изменений, `DS.subInk`.

`Сегодня`, `Просрочено`, `Завтра` — вне области, цвет не менялся
(`DS.todayInk` / `DS.danger` / `DS.warnInk` соответственно, как в
TASK_049).

---

## 2. `src/data/dateFormat.ts`

`UpcomingDateLabel` получил новое поле `days: number | null` — то же число,
что уже вшито в `primary` (`Через ${diff} ${pluralDaysRu(diff)}`), отдельно
для рендера. `null` для всех форм, кроме `Через N дней` (`overdue` /
`today` / `tomorrow` / `later` — без изменений). Расчёт `diff`,
`daysBetweenUTC`, пороги `SOON_DAYS`/`RELATIVE_HORIZON_DAYS` — не менялись;
`days` — то же самое число, что уже вычислялось, просто дополнительно
экспонировано, а не только вшито в готовую строку.

---

## 3. `UpcomingEventRow.tsx`

Когда `label.days != null`, строка рендерится тремя фрагментами вместо
одного `Text`:

```
"Через " (DS.navy) + <Text style={color: DS.todayInk}>{days}</Text> + " <плюрал>" (DS.navy)
```

Литерал `"Через "` и вызов `pluralDaysRu(label.days)` в компоненте
намеренно повторяют формат `primary` из `dateFormat.ts` — это осознанное
дублирование ради разделения слоёв (компонент не парсит строку регэкспом
обратно), а не рассинхронизация: оба места строят одну и ту же фразу из
одних и тех же данных (`diff`/`days`, `pluralDaysRu`).

Для всех остальных `urgency` (`overdue`/`today`/`tomorrow`/`later`) —
прежний единый `Text` с цветом из `URGENCY_COLOR` (TASK_049), без
изменений.

### Доступность

Внешний `Text` для строки `Через N дней` получил
`accessibilityLabel={label.primary}` — screen-reader читает `"Через 15
дней"` одной фразой, а не тремя фрагментами по границам вложенных `Text`.

- `src/components/__tests__/UpcomingEventsCard.test.tsx` — существующая
  проверка `toContain("Через 15 дней")` на составном `join(" ")`-выводе
  обновлена: добавлено схлопывание пробелов

  тестового хелпера (`collectText().join(" ")`), не признак лишнего
  пробела в реальном рендере (проверено отдельно живьём, см. §5).
