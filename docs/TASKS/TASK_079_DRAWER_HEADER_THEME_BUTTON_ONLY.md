# TASK_079 — Шапка шторки профиля: убрать ×, переключатель темы — крайняя правая кнопка

**Дата:** 21 сентября 2026
**Статус:** Implemented / deployed / production verified. Закоммичено
(`c19c4b2`), запушено в `origin/main`, задеплоено на GitHub Pages
(`gh-pages` `ebab3c5`), проверено на production (см. §4а).
**Скоуп:** только верхняя правая часть шапки `HomeDrawer` (`topRow` над
`ProfileSummary`) — кнопка ×, положение шеврона `›` и положение
переключателя темы ☼/☾. Остальная структура шторки, размеры карточки,

тап по backdrop, `onRequestClose`) — без изменений.

## 1. Что было

В `topRow` шапки шторки (`src/components/drawer/HomeDrawer.tsx`) лежали
две абсолютно позиционированные круглые стеклянные кнопки поверх
`ProfileSummary`: переключатель темы ☼/☾ (`themeBtn`, 36 px, `right:
CLOSE_BTN + 6` = 46) и кнопка закрытия шторки × (`closeBtn`, 40 px,
`right: 0`). `ProfileSummary` резервировал под обе кнопки `headTrailingSpace
= CLOSE_BTN_SPACE = 84` px паддинга справа в строке с именем — шеврон `›`
(`headChevron`, TASK_077) упирался в границу этого паддинга, то есть
заканчивался за 84 px до правого края шапки.

## 2. Что изменено

- Кнопка × (`closeBtn`, `XIcon`, `testID="drawer-close"`,
  `accessibilityLabel="Закрыть меню"`) удалена из `topRow` целиком —
  вместе с неиспользуемым импортом `XIcon` и стилем `closeBtn`.
- `themeBtn` переставлена на её место — крайняя правая кнопка:
  `right: 0` вместо `right: CLOSE_BTN + 6`. Размер (36 px), радиус,
  стеклянная заливка/обводка (`DRAWER_ICE.glass` / `.glassBorder`),
  `opacity: 0.92`, иконка ☼/☾ (`SunIcon`/`MoonIcon`, 19 px) и логика
  (`theme.cycle`, `accessibilityLabel` с текущим значением) — не
  изменились.
- Резерв под кнопки в `ProfileSummary.headTrailingSpace` уменьшен с
  `CLOSE_BTN_SPACE` (84) до нового `THEME_BTN_SPACE = THEME_BTN + 8 = 44`
  px — ровно ширина кнопки темы (36) плюс небольшой зазор (8) между ней и
  шевроном. Так как шеврон — последний flex-элемент строки перед этим
  паддингом (`headText` — `flex: 1`, `headChevron` идёт следом без
  собственного отступа справа), уменьшение паддинга автоматически
  сдвигает шеврон вправо ровно на освободившееся место (84 → 44, то есть
  на 40 px, что равно ширине убранной кнопки ×) — правка одной константы
  в `HomeDrawer.tsx`, без изменений в `ProfileSummary.tsx` самой.
- Закрытие шторки по-прежнему работает свайпом влево (`PanResponder`),
  тапом по backdrop (`drawer-backdrop`) и `onRequestClose` (аппаратная
  кнопка «назад» / жест ОС) — это не трогалось; тест на все три пути
  сохранён, только тап по × из него убран.
