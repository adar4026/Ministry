# TASK_056 — Unify event cards across Home / "Показать все" / "События"

## Запрос владельца

Унифицировать карточки событий на Главной («Ближайшие события» и
«Последние события») и во вкладке «Показать все» (`/upcoming-events`) по
образцу страницы «События» (`app/(tabs)/timeline.tsx`) — единая структура,
формат даты `ДД-ММ-ГГГГ`, единый формат относительного срока
(`через 1 мес. 6 дн.` / `прошло 1 мес. 6 дн.`), и красный цвет срока у
прошедших событий (сегодняшние — не считаются прошедшими, их стиль не
меняется). Страница «События» — визуальный эталон, её текущий пример и
внешний вид сохраняются.

Уточнения владельца (см. диалог):

1. Иконка ✏ на карточках Home/«Показать все» — **функциональная**:
   открывает ту же форму редактирования (`EventForm`/`TalkForm`) в `Modal`,
   как на «Событиях». Кнопка «Удалить» внутри формы не добавляется
   (`onDelete` не передаётся) — свайп-удаление остаётся только на
   «Событиях», это не часть запроса.
2. Область правок — три поверхности: «Ближайшие события» (Home),
   «Показать все» (`/upcoming-events`), **и** «Последние события» (Home,
   `EventCard.tsx`) — тоже приводится к единому виду.
3. Красная логика распространяется и на саму страницу «События» (сейчас
   там elapsed статично янтарный) — иначе красная ветка нигде реально не
   видна, т.к. «Ближайшие события»/«Показать все» показывают только
   будущие даты.

## План реализации

- `src/data/constants.ts`: `UpcomingItem` дополняется полным исходным
  объектом (`event`/`talk`) — нужен для доступа к category/location/number
  и для передачи в `EventForm`/`TalkForm` при редактировании. Фильтрация,
  сортировка, лимит — без изменений.
- Новый `src/components/timeline/EventListCard.tsx` — единственная
  презентационная реализация 3-строчной карточки (точка+заголовок+✏ /
  дата+доп.инфо+бейдж / жирный relative-срок), взятая из текущей разметки
  `timeline.tsx` один-в-один (без своих radius/shadow — это зона
  обёртки). Цвет relative-срока: `TIMELINE_COLORS.durationAccent` для
  будущего и сегодня, `TIMELINE_COLORS.danger` для прошедшего (не сегодня).
- Новый `src/components/timeline/StaticCardShell.tsx` — тот же
  radius(20)+shadow, что даёт `SwipeableDeleteRow`, но без жеста (для
  карточек без свайпа).
- Новый `src/components/timeline/TalkBadge.tsx` — вынесенный бейдж речи
  (был инлайн в `timeline.tsx`).
- `app/(tabs)/timeline.tsx`: инлайн-разметка карточки заменяется на
  `<EventListCard />` внутри существующего `<SwipeableDeleteRow>` —
  визуально идентично, plus теперь elapsed краснеет для прошедших дат.
- `src/components/dashboard/EventCard.tsx` и
  `src/components/dashboard/UpcomingEventRow.tsx` переписываются как тонкие
  адаптеры над `EventListCard` + `StaticCardShell` (первый — для
  `MinistryEvent`, второй — для `UpcomingItem`), с новым `onEdit` пропом.
- `app/(tabs)/index.tsx`, `src/components/UpcomingEventsCard.tsx`,
  `app/upcoming-events.tsx`: добавляется состояние редактирования
  (`editEv`/`editTalk`) + `Modal` + `EventForm`/`TalkForm`, `onEdit`
  пробрасывается в карточки. Сортировка/фильтры/лимит (`HOME_LIMIT = 3`,
  past-only для «Последние события», future-only для «Ближайшие») — без
  изменений.
- Тесты во всех затронутых `__tests__` — обновляются под новую структуру.

## Architecture Review Checklist (ADR-007)

- Изменение по большей части презентационное (единый компонент карточки
  вместо трёх расходящихся реализаций) плюс одна целевая функциональная
  добавка — рабочая иконка ✏ на Home/«Показать все». Ни схема
  AsyncStorage, ни формат хранимых записей не менялись: `saveEvent`/
  `saveTalk` вызываются как и раньше, из уже существующих форм
  `EventForm`/`TalkForm`.
- `UpcomingItem` (`src/data/constants.ts`) расширен полем `event`/`talk` —
  это только форма runtime-объекта, который строится на лету в
  `upcomingItems()` и никогда не сериализуется в AsyncStorage; на формат
  хранения `mj_events_v1`/`mj_talks_v1` не влияет.
- Личные данные пользователя не затрагивались: `src/data/seed.js` не
  менялся, новых дефолтных данных не добавлено.
- Сортировка, фильтры, лимиты (`HOME_LIMIT = 3`, past-only для
  «Последние события», future-only для «Ближайшие»/«Показать все») —
  подтверждены построчно как неизменные при ревью диффа.
- `npx tsc --noEmit`, `npx jest` (66/66 suites, 957/957, 0 failed),
  `npx expo export --platform web` — все чисто.
- Живая проверка в Browser pane (мобильный viewport 375×812,
  localStorage-сид тестовых событий/речей): все три поверхности
  визуально идентичны эталону («События»), ✏ открывает
  `EventForm`/`TalkForm` с исходными данными, красный цвет подтверждён на
  прошедших датах, оранжевый — на будущих и на «Сегодня»; после проверки
  тестовые данные удалены из localStorage.
- Deploy — по решению владельца, после прохождения этого checklist.
