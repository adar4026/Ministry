## 1. Цель

В карточке месяца Главной (`HoursHeroCard`) убрать третью статистику
«В среднем» без пустой колонки на её месте, увеличить и сбалансировать два
оставшихся элемента («Осталось», дни до конца месяца), и слегка улучшить
визуальные пропорции кольца процента (`HeroProgressRing`) — без изменения
концепции, данных или остальной части карточки/экрана.

## 2. Область изменений

- `src/components/dashboard/HoursHeroCard.tsx`:
  - удалён третий элемент статистики «В среднем» целиком: импорт
    `ChartIcon` (`@/components/icons`), вычисление `paceText`
    (`requiredPerDay`/день), сам `<StatItem>` и его разделитель — пустой
    третьей колонки не остаётся;
  - строка статистики (`statsGrid`) переведена на
    `justifyContent: "space-between"` вместо трёх сжатых в ряд колонок —
    два оставшихся элемента («Осталось», дни) используют освободившуюся
    ширину карточки, не растягиваясь принудительно на равные половины
    (это сохраняет полное отображение длинных значений вроде «Цель
    достигнута» без обрезания);
  - иконки `ClockIcon`/`CalendarIcon` увеличены (`14` → `16`), значение
    (`statValue`) увеличено (`12` → `15`), подпись (`statLabel`) увеличена
    (`10` → `11`), вертикальный разделитель между двумя элементами выше и с
    большим отступом (`28`/`6` → `34`/`14`) — визуально «два намеренных
    элемента», а не «три минус один»;
  - `remainingText`/`daysText` и их источники данных (`monthProgress()`,
    `p.hoursRemaining`, `p.daysLeft`, `dayWord()`) не изменялись — только
    отображение.
- `src/components/dashboard/HeroProgressRing.tsx`:
  - отношение толщины обода к размеру кольца уменьшено (`size * 0.23` →
    `size * 0.19`) — более тонкий, аккуратный обод; концепция (круговой
    индикатор, процент по центру, непрерывный цвет по прогрессу,
    масштабирование шрифта по количеству цифр, защита от `NaN`/`Infinity`)
    не менялась.
- `src/components/dashboard/__tests__/HoursHeroCard.test.tsx`: тест на
  «трёхэлементную строку» переписан на «двухэлементную» (`toContain("В
  среднем")` → `not.toContain`), остальные тесты файла не менялись.
