# TASK_010 — Home Redesign (compact overview) + Hours owns "Начать служение"

**Статус:** В РЕАЛИЗАЦИИ.
**Основание:** ADR-004 (нет TASK — нет кода). Владелец одобрил продуктовые
и UX-решения, см. ниже. Продолжает TASK_007 (Home Redesign) — не отменяет
его, сужает и переоформляет главную карточку.

---

## 1. Цель

Главная становится компактным, overview-ориентированным экраном, который
прежде всего отвечает на вопрос «как я продвигаюсь к месячной цели?».
Начало служения (таймер) больше не живёт на Главной — им владеет экран
«Часы», где уже существует соответствующее действие.

Только визуальный редизайн + перенос действия. Модель данных, агрегация и
`StoreContext` не меняются (ADR-002/003). Палитра — только Home-локальные
токены `DS` (`src/components/dashboard/tokens.ts`), глобальный `COLORS` не
изменяется (см. TASK_007).

## 2. Область изменений

- Шапка Главной (заголовок, дата, аватар) — компактнее, заголовок в одну
  строку на стандартных ширинах.
- Фон Главной — мягкий вертикальный градиент (приглушённый
  шалфейно-бирюзовый → почти белый), вместо плоского `groupedBg`.
- Карточка месячного прогресса (`HoursHeroCard`) — компактный
  двухколоночный вид: слева часы + «из N ч», справа компактное кольцо
  (только процент внутри), снизу — сдержанный текст «осталось часов» /
  «дней до конца месяца». Убираются: сегментированный бар, дублирующий
  текст процента, цветные точки-чипы, кнопка «Начать служение».
- Кнопка «Начать служение» с Главной убирается. Найдено: экран «Часы»
  (`app/(tabs)/hours/index.tsx`) уже содержит эквивалентное действие —
  `QuickActionsRow` → «Таймер / Начать служение» → `/hours/timer` (первый
  пункт, выше сгиба). Изменения в `app/(tabs)/hours/index.tsx` и
  `QuickActionsRow.tsx` **не требуются** — консолидация, не дублирование.

## 3. Вне области (не трогаем)

- «Ближайшие события», «Текущий служебный год», «Последние события»,
  нижняя навигация, центральная «Добавить» — без изменений (данные,
  навигация, вёрстка).
- Экран «Часы» — без изменений (действие уже существует).
- Глобальные `COLORS`, модель данных, `StoreContext`, таймер/сессии.
- Релизные операции: commit/push/deploy/tag/version bump — не выполняются
  в рамках этой задачи.

## 4. Данные и расчёты (переиспользование)

- `monthProgress(records, now, sessions)`, `MONTHLY_GOAL`, `formatHM`,
  `dayWord` — без изменений, без новой логики агрегации.
- «Цель не задана»: `MONTHLY_GOAL` — константа (=50), пользовательских
  настроек цели в модели данных нет; ветка обрабатывается защитно
  (`MONTHLY_GOAL <= 0`) без добавления UI редактирования цели.

## 5. Definition of Done

- `tsc --noEmit` — чисто; `npm test` — зелёно (существующие 124 + новые
  тесты `HoursHeroCard`).
- Главная не содержит «Начать служение»; на «Часах» действие подтверждено
  и осталось единственным.
- Нижние секции Главной — без функциональных/структурных изменений.
- Не выполняется commit/push/deploy/tag/version bump — оставлено владельцу.

## 6. Дополнение — быстрый ручной ввод времени с карточки (после Opus-ревью)

**Продуктовое решение владельца:** добавить сдержанную круглую кнопку «+» в
нижнюю правую область карточки «Этот месяц» — быстрый переход к ручному
вводу уже отслуженного времени. Кнопка **не** запускает таймер служения
(это по-прежнему исключительно зона экрана «Часы»).

**Переиспользуемый маршрут:** `/hours/entry` — существующий экран Manual
Time Entry (TASK_005B, `app/(tabs)/hours/entry.tsx`), `SessionForm` +
`store.saveSession()`. Это тот же маршрут, что уже использует `Часы` →
`QuickActionsRow` → «Добавить время». Центральная вкладка «Добавить»
(`app/(tabs)/add.tsx`) ведёт к другому, легаси-потоку (`RecordForm`,
помесячные итоги `HourRecord`, заморожен) — не переиспользуется и не
изменяется.

- Новой формы/маршрута/логики сохранения не создано — только навигация
  (`router.push("/hours/entry")`) на существующий экран.
- После сохранения `Session` через существующий `saveSession()` Главная
  обновляет значения автоматически через `StoreContext` — подтверждено
  живой проверкой (сохранена сессия 60 мин → карточка сразу показала
  «1 ч / 2% / Осталось 49 ч» без дополнительного кода).
- Доступность: `accessibilityRole="button"`, `accessibilityLabel="Добавить
  часы"`; кнопка — независимый фокусируемый элемент (не поглощён
  `accessible`-сводкой карточки), идёт в порядке чтения после сводки
  оставшихся часов/дней.
- Нижняя строка карточки переведена с горизонтального ряда (текст · текст)
  на вертикальный стек из двух строк — иначе на узких экранах (375px)
  текст сталкивался с кнопкой и перенос слов ломал вёрстку (обнаружено и
  исправлено в рамках этого дополнения).
- Файлы: `src/components/dashboard/HoursHeroCard.tsx` (кнопка + вёрстка
  footer), `src/components/dashboard/__tests__/HoursHeroCard.test.tsx`
  (+2 теста: рендер кнопки с меткой, навигация на `/hours/entry` а не на
  таймер). `app/(tabs)/add.tsx`, `TabBar.tsx`, `hours/entry.tsx`,
  `SessionForm` — не изменялись.
