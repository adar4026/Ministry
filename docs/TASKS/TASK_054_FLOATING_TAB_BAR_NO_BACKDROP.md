# TASK_054 — Убрать полноширинную «штору» за нижней панелью

**Статус:** реализовано, протестировано
**Область:** только механизм нижнего отступа/фона сцены под плавающей
`TabBar` — `app/(tabs)/_layout.tsx` (`sceneStyle.paddingBottom`) и нижний
`paddingBottom` содержимого `ScrollView` на каждом экране, где показывается
нижняя навигация.
**Не входит:** сама `TabBar.tsx` (форма, скругления, белый фон, тени,
активное состояние, центральная кнопка «Добавить») — не трогается; верхние
хедеры, карточки, типографика, вёрстка, бизнес-логика экранов — не
трогаются; `/entry` и `/upcoming-events` (корневые маршруты вне `(tabs)`,
нижняя навигация там не показывается).

---

## 1. Проблема

Владелец обнаружил на всех экранах с нижней навигацией широкую нижнюю
белую/светлую «штору» — плоский прямоугольник на всю ширину экрана,
визуально отличающийся по цвету от фона страницы, который сидит позади
`TabBar` и создаёт шов между контентом и панелью.

## 2. Причина

`app/(tabs)/_layout.tsx` красит **сцену Tabs-навигатора** (общий контейнер
вокруг содержимого каждой вкладки) в `COLORS.bg` (`#f8fafc`) и резервирует
под неё `paddingBottom: bottomInset` (высота бара + safe-area + отступ) —
для всех вкладок, кроме Главной (там `isHome` уже даёт `paddingBottom: 0`,
исправлено в TASK_048/053).

Каждый экран сам рисует **свой** фон (`DS.homeBase` на Часах/Событиях/
Профиле, `COLORS.groupedBg` на «Детали месяца»/статистике, свой
`screenBackground`/`safe` на Истории/Таймере) поверх `flex: 1`-контейнера,
который заполняет высоту **за вычетом** внешнего `paddingBottom` сцены.
Получаются два слоя фона разных цветов: экран сверху, а в зарезервированной
полосе внизу (ровно там, где плавает `TabBar`) просвечивает нижний слой —
`COLORS.bg` сцены. Это и есть визуальная «штора»: сплошная полоса другого
оттенка на всю ширину, позади панели.

На Главной той же проблемы нет именно потому, что там `paddingBottom` сцены
уже `0`, а необходимый отступ вместо этого добавлен самим экраном — на
`contentContainerStyle` его `ScrollView` (`useTabBarContentInset()`), так
что фон экрана заполняет всю высоту без чужого слоя позади.

## 3. Решение

Распространить уже существующий (и уже проверенный на Главной, TASK_048)
паттерн на все остальные экраны, где показывается нижняя навигация:

1. `app/(tabs)/_layout.tsx` — `sceneStyle.paddingBottom` всегда `0` (не
   только для `isHome`); внешний слой фона сцены сзади никогда не виден.
2. Каждый экран с нижней навигацией сам добавляет нижний отступ на
   **содержимое своего скролла** через `useTabBarContentInset()`
   (`src/components/TabBar.tsx`, уже существующий хук — та же геометрия
   бара, что использует сама `TabBar`), вместо фиксированного числа.
   Фон экрана (`View`/`SafeAreaView`, `flex: 1`) заполняет весь доступный
   размер без чужого слоя позади — контент и панель — на одном фоне.

Экраны:
- `app/(tabs)/hours/index.tsx`
- `app/(tabs)/timeline.tsx`
- `app/(tabs)/profile.tsx`
- `app/(tabs)/add.tsx`
- `app/(tabs)/hours/history.tsx`
- `app/(tabs)/hours/month/[key].tsx`
- `app/(tabs)/hours/timer.tsx` (все 6 состояний/`ScrollView`)
- `app/(tabs)/hours/stats/index.tsx`
- `app/(tabs)/hours/stats/month/[key].tsx`
- `app/(tabs)/hours/stats/year/[key].tsx`

(`app/(tabs)/index.tsx` — уже корректен, не трогается.)

- `npx jest` — **964/964, 0 failed** (66/66 suites, без изменений — диф чисто
  презентационный, отдельных новых тестов на «штору» не добавлялось).
- Живая проверка — dev-сервер (`expo start --web`, порт 8082), мобильный
  viewport 375×812 (iPhone), `localhost:8082`, каждый экран из списка §3
  (index/history/month/timer/stats + timeline/profile/add), докрученный до
  самого низа списка/формы:
  - Ни на одном экране нет сплошной полосы другого цвета позади `TabBar` —
    `document.elementsFromPoint()` на нижней кромке подтвердил, что фон
    экрана (не сцены) заполняет весь `375×812` без зазора.
  - Последний элемент списка/формы на каждом экране полностью
    прокручивается выше панели (Профиль — «Обратная связь», История —
    «1 авг. 2026», Add — форма речи «Сохранить», Timeline — «Переезд в
    Хихон» и т.д.).
  - Переключение между вкладками — без мигания/скачка цвета.
  - Консоль браузера в новой вкладке (без унаследованного HMR-состояния
    от правки файлов) — без ошибок.
  - `TabBar.tsx` не менялась — форма, скругления, тени, белый фон,
    активное состояние, кнопка «Добавить» визуально подтверждены
    неизменными на всех экранах.

## 5. Критерии приёмки

- На всех перечисленных экранах нет сплошной полосы другого цвета позади
  `TabBar` — фон экрана и карточки естественно продолжаются за панель.
- Последний элемент каждого списка полностью прокручивается выше верхнего
  края панели (запас = высота бара + safe-area + прежний зазор,
  `useTabBarContentInset()`), не только частично.
- `TabBar.tsx` не менялась: форма, скругления, тени, белый фон, активное
  состояние, центральная кнопка «Добавить» — как были.
- Переключение между вкладками не даёт визуального мигания/скачка цвета.
- `npx tsc --noEmit` и `npx jest` — чисто.
