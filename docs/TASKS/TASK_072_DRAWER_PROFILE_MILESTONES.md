# TASK_072 — Шторка «Профиль»: убрать «Памятные даты», переработать блок дат

**Дата:** 20 сентября 2026
**Статус:** Реализовано, подтверждено владельцем 2026-09-20 → commit + deploy
**Скоуп:** боковая шторка Главной (`HomeDrawer`, TASK_066) — верхний блок
профиля (`ProfileSummary`) и группа ПРОФИЛЬ. Аватар, имя, подпись «Личный
профиль», кнопка ×, группы СЛУЖЕНИЕ / ПРИЛОЖЕНИЕ / ДАННЫЕ / О ПРИЛОЖЕНИИ,
их пункты, мятный фон, навигация, страница «Профиль» (`ProfileHeroCard`) —
без изменений.

---

## 1. Что нужно

1. Из группы ПРОФИЛЬ убрать строку «Памятные даты · N из 3». Остаётся
   одна строка «Личные данные» — одиночная цельная карточка с полными
   скруглениями, без пустого места и без «обрезанного списка».
2. Блок под именем (сейчас — три строки «КРЕЩЕНИЕ / ПИОНЕР / ХИХОН» капсом
   с датой и сроком справа, без подложки) переработать: спокойный
   iOS-style «премиальный список» личных milestones — лёгкая структура,
   мягкая подложка, ровные интервалы, ясная иерархия «дата — главный факт,
   срок — второстепенный teal». Без тяжёлых карточек, без инфографики.

Сущности остаются `profile.events` (три пользовательские записи, TASK_042):
названия — как ввёл пользователь (Title Case, без `textTransform`),
данные и редактор не меняются; редактируются они по-прежнему тапом по
блоку профиля (и по «Личные данные» — тот же `ProfileEditSheet`).

## 2. Реализация

### 2.1 `ProfileSummary.tsx` — блок milestones

- Подложка `events`: одна мягкая стеклянная поверхность — `rgba(255,255,255,0.42)`,
  radius 18, hairline `rgba(255,255,255,0.65)`, `overflow hidden`, без тени.
  Не второй `DrawerGroup` (у того плотнее стекло и заголовок) — это часть
  hero-зоны профиля, а не секция настроек.
- Строка `eventRow`: `paddingVertical 10`, `paddingHorizontal 14`, между
  строками hairline-разделитель `rgba(15,42,38,0.10)` (у последней нет).
  Слева — небольшой teal-маркер (6 pt точка на `MINISTRY.accent`) +
  название `15/600 ink`, `letterSpacing −0.1`, без uppercase, до 2 строк.
  Справа — колонка, `flexShrink 0`, выровнена вправо: дата `15/700 ink`
  `tabular-nums`; срок `12/600 MINISTRY.primary`, `marginTop 1`.
- `wrap.gap` 12 → 14: блок отделён от имени, но остаётся частью hero.
- `accessibilityLabel` строк без изменений (`Событие: …`).
- Новый проп `headTrailingSpace` — `paddingRight` только у строки имени:
  шторка накладывает туда кнопку ×, а блок дат идёт на всю ширину summary
  (раньше summary делил строку с × и блок был на 50 px уже карточек).

### 2.2 `HomeDrawer.tsx` — группа ПРОФИЛЬ

- Удалить `ProfileSettingsRow` «Памятные даты», `datesSubtitle`,
  `MAX_PROFILE_EVENTS`, импорт `StarIcon`; «Личные данные» получает `last`.
  `DrawerGroup` уже рисует одну карточку с radius 22 и `overflow hidden`;
  с одной строкой без делителя она — цельная одиночная ячейка.
- `StarIcon` в `icons.tsx` удалить (единственный потребитель ушёл).
- `topRow` больше не flex-row: `ProfileSummary` на всю ширину, `closeBtn`
  — `position absolute` в правом верхнем углу (`top 6 / right 2`), 44×44.
