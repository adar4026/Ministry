# ADR-008 — Маршрутизация AI-моделей: прямые маршруты + Hermes Gateway

**Дата:** Июль 2026
**Статус:** Принято

**Решение:** Каждый AI-инструмент подключается к своему провайдеру
**напрямую**; единственный разрешённый посредник — Hermes Gateway
(локальный шлюз-переводчик Anthropic ⇄ OpenAI, `127.0.0.1:8787`) — и только
для моделей, недоступных по Anthropic-протоколу (сейчас: Nemotron через
OpenRouter). Универсальный маршрутизатор CCR (claude-code-router) выведен
из эксплуатации.

Закреплённые маршруты:

| Инструмент | Маршрут |
|---|---|
| ChatGPT (архитектор) | напрямую OpenAI |
| Codex (реализация) | нативный вход ChatGPT (`gpt-5.5`) |
| Claude Code — `claude` | напрямую `api.anthropic.com` |
| Claude Code — `claude nm` | Hermes Gateway → OpenRouter → Nemotron |
| DeepSeek (при необходимости) | нативный endpoint `api.deepseek.com/anthropic`, без прокси |

**Обоснование:**
- Каждый лишний слой маршрутизации — дополнительная точка отказа для
  streaming, tool-use и кодировки UTF-8 (инцидент mojibake TASK_005D,
  коммит `b8d1a4d`).
- Опыт CCR показал риски универсального middleware: баг диспетчеризации
  (Nemotron недостижим при любой конфигурации) и автоматическое
  переписывание чужих конфигов (`~/.claude/settings.json`,
  `~/.codex/config.toml`), вызвавшее каскад проблем с подключениями.
- DeepSeek не нуждается в трансляции вовсе — у провайдера есть нативный
  Anthropic-совместимый endpoint.
- Hermes Gateway — минимальный, локальный, тестируемый (чистые функции
  трансляции без сетевых зависимостей), с собственной документацией.

**Альтернативы, которые не выбрали:**
- CCR как единый маршрутизатор всех моделей — отклонено (см. выше;
  подробный post-mortem: `Hermes-Gateway/docs/architecture.md`).
- Отдельный прокси для каждого провайдера — избыточно: прямые маршруты
  покрывают всё, кроме OpenAI-only моделей.

**Правила:**
- Обычный `claude` никогда не перенаправляется: ветка по умолчанию
  shell-функции `claude()` обязана снимать (`unset`) переменные
  `ANTHROPIC_*` — эту ветку не изменять.
- Никакой инструмент не имеет права автоматически переписывать конфиги
  других инструментов.
- Маршрут, записывающий исходники с не-ASCII текстом, предварительно
  проходит проверку сохранности UTF-8 (см. `docs/AI_INFRASTRUCTURE.md`, §8).

**Подробности инфраструктуры:** `docs/AI_INFRASTRUCTURE.md`.
