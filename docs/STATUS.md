### Архитектура и модель данных

- Expo + React Native (expo-router, TypeScript), Expo SDK 54.
- Единый `StoreContext` — вся работа с данными идёт только через него.
- **Session-first агрегация (TASK_005A):** для каждого месяца
  авторитетный источник ровно один — `Session`, если для месяца есть хотя
  бы одна запись, иначе легаси `HourRecord`. Источники никогда не
  смешиваются. Реализовано в `src/data/constants.ts`:
  `monthTotal()`, `sessionsForMonth()`, `serviceYearAggregation()`.
- **Статистика (TASK_005E):** чистые функции в `src/data/stats.ts`;
  компоненты в `src/components/stats/` (MonthlyStatsCard,
  ServiceYearStatsCard, TrendChart, PaceCard, ProjectionCard) +
  `src/components/HeatMap.tsx`.
- **Правило блокировки легаси-записи (TASK_005B):** единая точка
  проверки — `legacyEntryBlockReason()` в `src/data/constants.ts`;
  легаси-форма отказывает для текущего/будущих месяцев и прошлых месяцев
  с сессиями, с явным пояснением в форме.
- **Таймер (TASK_005C):** `TimerState` — управляющее состояние
  (crash-recovery), не отчётная сущность; ключ `mj_timer_v1`; логика —
  `src/data/timer.ts`, жизненный цикл — `src/hooks/useTimer.ts`.
