# Ministry

Личный журнал теократического служения (Expo + React Native, expo-router).
История служения с 2003 года: часы, события, публичные речи.

- Документация: `docs/` — ARCHITECTURE, STATUS, DECISIONS, ADR/, TASKS/
- Веб-версия (PWA): https://adar4026.github.io/Ministry/
- Запуск: `npm install && npx expo start` · Тесты: `npm test`
